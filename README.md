# 932402.UgorelovaVera.UNIX.Lab1
Лабораторная 1 по курсу "Операционная система UNIX" ИПМКН ТГУ, 2026 год
Содержит скрипт script.sh для сборки исходных файлов C/C++/TeX

Исходный файл подается в качестве аргумента (Например, "script.sh hello.c"), происходит сборка файла во временном каталоге и сохранение результата в файл, название которого находится в комментарии исходного файла после ключевого слова output:

Результат копируется в исходную папку, временный каталог удаляется вместе с содержимым. В случае ошибок программа выдает предупреждение о ошибке и разрушает все временные файлы, которые на этот момент были созданы

В качестве примеров тестов приведено несколько файлов, по одному на каждый язык.
